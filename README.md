# SafeDrive - FatigueGuard Landing Page

## Descripción del proyecto

SafeDrive es una startup académica que desarrolla FatigueGuard, una solución digital orientada a prevenir accidentes de tránsito causados por fatiga en conductores.

FatigueGuard es una aplicación móvil que utiliza inteligencia artificial y análisis facial desde la cámara del smartphone para detectar señales de cansancio, somnolencia o pérdida de concentración durante la conducción.

## Objetivo de la Landing Page

La Landing Page tiene como objetivo presentar la propuesta de valor de FatigueGuard, explicar el problema de la fatiga al conducir, mostrar las características principales del producto y captar el interés de usuarios potenciales.

## Segmentos objetivo

### Conductores de transporte público

Conductores que realizan jornadas extensas y necesitan una herramienta preventiva que les alerte cuando presentan señales de fatiga.

### Doctores

Profesionales de la salud que pueden revisar el historial de fatiga del paciente como información complementaria para su evaluación clínica.

## Principales características

- Evaluación inicial del conductor antes de manejar.
- Monitoreo facial en tiempo real mediante smartphone.
- Detección de señales de fatiga como ojos cerrados, bostezos o cabeceo.
- Alertas visuales, sonoras y por vibración.
- Recomendación de pausa segura.
- Historial de eventos de fatiga.
- Información complementaria para doctores.

## Tecnologías utilizadas

- HTML5
- CSS3

- Google Fonts
